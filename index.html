    How to edit
    • Draw with the toolbar on the map (points, lines, polygons) — new shapes go into the active layer.
    • Edit shape: use the edit, drag and cut tools. Remove with the bin tool.
    • Edit data: click a cell in the table, or click a feature on the map. Use Undo for recent cell and field edits, and the arrows in a column header to sort.
    • Export filenames: select a feature, then choose a column value for the filename when downloading its layer.
    • Add attributes with “＋ Field” above the table. Click a column name to rename or change its type.
    • Bulk delete: choose a column and condition, enter one allowed or matching value per line, then review the count and confirm. This affects the whole active layer, not just filtered rows. Download a backup first; deletions cannot be undone.
    • Shapefile export: choose the attribute columns to include and optionally a QGIS category column. Extract the ZIP and keep the matching .qml beside the .shp. In QGIS, expand the layer to toggle categories; if the style is not loaded automatically, use Layer Properties → Symbology → Style → Load Style and select the .qml.
    • Symbol styles: edit each category's point shape/size, line style/width, polygon fill/outline, colours and opacity in the export dialog. Import an existing .qml to reuse its simple symbols, or download the edited .qml on its own. Imports copy symbol appearance and category labels/visibility only, not labeling or other layer settings. Sizes use millimetres. Advanced renderers, multi-layer symbols and data-defined styles require QGIS.
    • Bulk style edits: with a category column selected, open “Bulk edit categories” in the style editor. Filter and tick the categories, tick the properties to change (shape, size, colour, pattern, outline, opacity, initial visibility), then Apply. Colours can be one colour, distinct colours, or a gradient across the selected categories. You can also copy one category's whole symbol to the others, and undo bulk changes.
    • Legend order: select a category column, then choose a legend sort column and ascending or descending order. This orders the QGIS legend, not the map's drawing order or shapefile records. Symbol edits are preserved.
    • Shapefile downloads are always WGS84 (EPSG:4326). Mixed layers are split per geometry type.
