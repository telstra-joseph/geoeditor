    How to edit
    • Start: choose New layer to create a blank layer or upload files. You can also drop files onto the page.
    • Draw: select a layer, then use the map tools. On mobile, double-tap the current tool to open or close its group.
    • Edit shapes: use the edit, drag, cut or remove tools.
    • Edit data: change table cells or use Field to add a column. Click a column name to rename it or change its type. Undo reverses recent cell and field edits.
    • Find rows: filter or sort the table. On mobile, use the filter button; Clear filter restores all rows. Drag column edges to resize them.
    • Download: choose the active layer or all layers, then a format. A row's download icon exports just that feature. Selected-feature values can be used as filenames.
    • QGIS styles: shapefile export includes column, category, symbol and legend options. Keep each .qml beside its matching .shp. Exports use WGS84; mixed layers split by geometry type.
    • Delete carefully: bulk deletion affects the whole active layer, including hidden rows. Deletions cannot be undone.
    • Save your work: choose Session to save locally before refreshing or closing the tab. Only one session is stored; saving replaces it. The saved session restores automatically. Download files for a portable backup.
